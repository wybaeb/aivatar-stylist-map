# Айватар · карта историй ИИ-стилиста

Интерактивная User Story Map пайплайна подбора одежды: горизонталь — шаги пайплайна
(источники → сбор → карточка → цвет → теги → стили → сочетаемость → лук → человек → проверка),
вертикаль — срезы улучшений. Жёлтая полоса — «рыбий скелет», минимальный сквозной первый релиз.

Данные стикеров — `data.js`, страница — `index.html`, без сборки и зависимостей.
